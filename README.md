## 以后怎么加新东西

1. 在 GitHub 上点开 [`items.js`](items.js)，按右上角铅笔 ✏️ 编辑。
2. 复制一段 `{ title: ..., url: ..., ... },`，贴在想放的那一组里，改成新的标题、网址、标签和介绍。
3. 图标可以写一个汉字（例如 `icon: "医"`），也可以把图片传进 `icons/` 文件夹后写 `icon: "icons/图片名.png"`。
4. 按 **Commit changes** 存档，大约一分钟后网页就会更新。

> 这个网页是公开的，任何人都能打开。不要把私密资料或私密仓库的内容放上来。
